The Complete System Architecture (User + Chef + Admin + Backend)

    The User App (The Consumer Front): The TikTok-style drop feed, WhatsApp share engine, NFC Membeprint tap-to-unlock, and micro-batch pre-order checkout.

    The Admin Dashboard (The Control Room): Your master command center to verify new cooks, oversee active drops, trigger or override micro-batch unlocks, manage the weekly Top Chef cash prize pool, and view real-time platform analytics.

    The Edge Backend (The Engine): Cloudflare Workers managing secure routing, webhook triggers, and automated state transitions when an order threshold is met.
